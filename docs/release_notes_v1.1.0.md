# v1.1.0 外文歌词双模式

新增原文与双语模式，默认双语优先。网易云提供且通过中文校验的译文作为理解辅助；没有可用中文译文时保留原文，不生成全量 AI 翻译。

原文默认预算 6000 字符、译文额外预算 2000 字符，Context 总上限默认 8000 字符（包含结构与提示）。原文优先，实际可用译文空间受总上限约束；展示模式、降级原因和截断状态进入 Context。

兼容旧歌词缓存，并对缺少翻译字段的旧条目进行有次数与冷却限制的补取。Context 缓存按模式和预算隔离，可选 Processor 在输入证据一致时安全复用，失败继续普通聊天。

已知限制：中文识别采用保守规则，简短、意象型、文言及部分繁体译文可能被拒绝；长歌词可能因硬性总上限挤压译文空间。这些属于后续样本验证与质量改进范围，不代表所有歌曲均已验证。旧历史不补写新模式字段，现有截图可能不包含新配置。

当前正式支持网易云音乐；不提供播放、下载或 AI 全量歌词翻译。其他平台尚未实现。
